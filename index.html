Catatan metodologis

Web ini tidak mengklaim menghitung PLS-SEM secara penuh. Dataset diekspor ke CSV dan hasil inferensial diolah di SmartPLS. Dashboard web menampilkan analisis deskriptif agar tidak mencampuradukkan scoring sederhana dengan estimasi PLS-SEM.
